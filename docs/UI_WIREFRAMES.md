## 3. 视频/RTSP 诊断页

```text
┌──────────────────────── 视频接入诊断 ─────────────────────────────────────┐
│ 目标 [摄像机 A ▼]  RTSP URL [rtsp://host:554/...                 ] [测试]   │
│ 传输 [TCP ▼]  超时 [5000 ms]  [显示高级参数]                                │
├─────────────────────────┬──────────────────────────┬────────────────────────┤
│ 视频预览/媒体信息        │ 诊断步骤                 │ 连接参数/资产信息       │
│                         │ ✓ TCP 连接  18 ms        │ 主机 / 端口             │
│      播放区域            │ ✓ RTSP 握手              │ 认证引用（不显示秘密）  │
│                         │ ! 鉴权失败               │ 码流 / 传输模式         │
│                         │ ○ SDP / RTP 未执行       │                         │
├─────────────────────────┴──────────────────────────┴────────────────────────┤
│ 底部标签：实时日志 | 原始响应（脱敏） | 流统计 | 报告预览                   │
└────────────────────────────────────────────────────────────────────────────┘
```
交互：未通过的前置步骤阻止依赖步骤，并将后续步骤标记为 Skipped，而非 Failed；允许用户展开脱敏后的响应细节。

## 6. 网络诊断页
- 顶部：目标输入、工具类型、超时、并发、运行/取消。
- 中部：结果摘要（成功/失败/未知）、逐目标结果表格。
- 详情：路由跳点、解析记录、TCP 错误、时间分布。
- 底部：命令输出、结构化事件、导出 CSV/JSON。
- 扫描类操作必须显示目标范围、端口范围、速率和授权确认。

## 7. 诊断任务详情页
- 摘要：目标、任务类型、整体状态、持续时间、版本。
- 时间线：每个步骤的开始/结束、状态、耗时和依赖。
- 证据：脱敏日志、错误码、响应摘要、文件引用与哈希。
- 结论区：确认事实、可能原因、未知项、下一步验证。
- 操作：重新运行、仅重试失败步骤、导出报告、复制脱敏摘要。

## 8. 报告预览页
- 左侧目录：摘要、目标、步骤、证据、建议、环境信息。
- 主区：专业报告版式，包含状态概览、表格和时间线。
- 导出：HTML（P0）、Markdown/PDF（P1）；默认脱敏。
- 报告中区分观测事实和推断建议，标注产品版本、生成时间与数据范围。

## 9. 设置页
- 常规：主题、语言、缩放、快捷键。
- 网络：代理、DNS/超时默认值。
- 安全：凭据存储、脱敏规则、导出警告。
- 存储：项目目录、日志保留、缓存清理。
- 插件：版本、能力、来源、哈希/签名状态、启用/禁用。
- 诊断包：打包应用日志与环境信息前显示敏感信息预览。

## 10. 视觉规范建议
- 深色为默认候选主题，同时提供浅色主题。
- 使用统一间距、字体层级、圆角、表格行高与状态色 Token。
- 状态必须同时使用图标/文字，避免仅靠颜色表达。
- 重点数据采用紧凑表格与时间线；避免过度卡片化。
- 适配 1366×768 起步，推荐 1920×1080；支持 DPI 缩放。
- 所有长任务有明确运行态、进度、取消和错误恢复。
