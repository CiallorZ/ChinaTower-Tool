# LinkForge v1.1.0

LinkForge v1.1.0 是 `1.x` 系列的功能增量版本，重点补齐协议选择、可移植项目包、
Windows 本机凭据保护与发布可追溯性。

## 主要更新

- MQTT 工作台支持 MQTT 3.1.1 与 MQTT 5.0 真实协议选择，默认仍为 3.1.1。
- 版本化 `.lfpkg` 项目包可导入/导出项目、环境和资产，不包含凭据明文；
  导入使用严格 schema 校验与单事务失败回滚。
- 资产密码可使用 Windows DPAPI CurrentUser 保存到当前用户本机凭据库；
  项目包、日志、历史、剪贴板、导出与报告只保留凭据引用键。
- 新增 Windows CI：Release 构建、全量测试与未签名 `win-x64` 诊断包。
- 继续提供未签名的双架构 Inno Setup 用户级安装器与 `win-x64` / `win-x86`
  自包含便携包，包含依赖清单、CycloneDX SBOM 与 SHA-256。

## 安全与范围边界

- 安装器和便携包**未签名**，Windows SmartScreen 可能提示未知发布者。
- DPAPI CurrentUser 只保护当前 Windows 用户在本机的秘密，不支持跨机同步，
  也不能防御已经以同一用户身份运行的恶意软件。
- 海康/大华厂商 SDK、GB/T 28181、RTP 接收、媒体解码与持续播放未交付。
- 抓包、端口/安全扫描与渗透攻防工具未交付，授权边界仍未确认。
- Windows 10 真机、高 DPI、完整键盘/辅助功能验收与代码签名仍为后续工作。
