# Codex 开发启动提示词

请先阅读仓库中的 `LinkForge_UI_Design_Guidelines_V1.1.md`，并将它作为 UI 开发强约束。同步阅读现有 PRD、功能树、架构、线框与任务拆解文档。

第一轮不要直接大规模改代码。请先：
1. 检查仓库结构、目标框架、WPF UI 方案、主题/导航机制和现有组件；
2. 识别与规范不一致的地方，并列出可复用资产；
3. 提交按阶段实施计划，说明改动文件、风险和验证方式；
4. 先实现设计令牌、基础控件、应用壳层和状态组件，再逐页改造业务页面。

严格要求：
- 不得只做静态样式，不得用假数据伪装真实功能；
- 不得擅自删减 PRD 功能或重写整体架构；
- 长任务不得阻塞 UI 线程，能取消的任务必须提供取消入口；
- 凭据在日志、历史、复制和报告中默认脱敏；
- 每阶段运行构建/测试并报告结果；
- 页面需覆盖空、加载、运行、成功、部分成功、失败、取消及依赖缺失等适用状态。
