# 视联网全链路调试工具箱 — 产品需求规格说明书（PRD）

版本：V1.0  
日期：2026-10-15  
产品代号：LinkForge（暂定）  
目标平台：Windows 10/11 x64，后续评估 ARM64  
文档状态：立项与 MVP 设计基线

## 1. 产品概述

### 1.1 产品定位
LinkForge 是面向视频监控、视联网、物联网和平台集成工程师的 Windows 桌面工程工作台。它将设备资产、协议调试、网络诊断、API 联调、日志证据和报告输出整合为一套可复用的工程流程。

产品不以“工具数量”为唯一目标，而以“可复现诊断流程 + 可解释证据 + 可复用项目配置”为核心价值。

### 1.2 目标用户
- 研发工程师：验证 SDK、协议、接口和数据格式。
- 实施/交付工程师：现场设备发现、接入联调、验收。
- 运维工程师：定位离线、黑屏、超时、丢包和服务异常。
- 测试/安全工程师：授权范围内的资产检查、基线检查、回归测试。
- 系统集成商：维护多项目、多厂商设备配置与标准化报告。

### 1.3 核心场景
1. 摄像机无法播放：逐阶段检查网络、端口、RTSP 鉴权、SDP、RTP、解码。
2. MQTT 无消息：检查 Broker、TLS、ACL、Topic、订阅确认、QoS 与 Payload。
3. 平台 API 超时：检查 DNS、TCP、TLS、代理、HTTP 状态和响应耗时。
4. 现场验收：导入设备清单，批量诊断，生成带证据的 HTML/PDF 报告。
5. 复现问题：保存项目环境、工具参数、脱敏日志和可重复执行的诊断任务。

### 1.4 产品原则
- 本地优先：项目、日志、抓包和历史记录默认保存在本机。
- 证据优先：明确区分“已确认事实”“推测原因”“未知/未检测”。
- 插件化：厂商 SDK、协议和系统能力通过适配器隔离。
- 安全默认：凭据加密、日志脱敏、目标范围确认、主动扫描限速。
- 渐进交付：先做高频可用路径，再扩展低频协议。
- 不伪装能力：不支持的设备/协议必须清晰提示，而非返回误导性成功。

## 2. 产品目标与非目标

### 2.1 MVP 目标
- 建立 Windows 桌面基础框架与统一视觉系统。
- 提供项目/环境管理、设备台账、网络基础诊断。
- 提供 HTTP API 调试、MQTT 基础调试、RTSP 连通性与播放验证。
- 建立统一任务、结构化日志、诊断结果与 HTML 报告。
- 具备基本安全基线：凭据保护、日志脱敏、任务取消、授权目标确认。

### 2.2 MVP 成功指标（建议验收口径）
- 新建项目并保存配置：≤ 2 分钟。
- HTTP 请求可查看状态码、响应头、响应体和分阶段耗时。
- MQTT 可连接、订阅、发布、查看消息并导出记录。
- RTSP 诊断能区分网络连接失败、协议/认证失败、媒体接收失败和解码失败（对实际可观测的阶段）。
- 诊断任务可取消；日志可按任务 ID 过滤。
- 报告能导出目标、执行步骤、结果、证据、时间和版本信息。
- 敏感字段在日志和报告中默认遮蔽。
- 所有核心模块有自动化测试或可重复的手工验收步骤。

### 2.3 非目标（MVP 不做）
- 自研完整视频解码器或完整 Zigbee 协议栈。
- 自动破解口令、未经授权的漏洞利用、隐蔽扫描。
- 云端强制账号体系、团队协作后台、SaaS 资产管理。
- 承诺支持所有海康/大华型号及所有私有 SDK 版本。
- 自动修改生产设备配置或执行高影响操作。
- AI 自动根因结论替代工程师判断。

## 3. 功能范围与优先级

优先级定义：P0 = MVP 必须；P1 = 第一阶段增强；P2 = 后续扩展。

### 3.1 工作台与项目管理
- P0：创建/打开/关闭项目；项目名称、描述、环境、默认超时。
- P0：最近项目、最近任务、常用工具快捷入口。
- P0：项目级配置持久化；导入/导出项目包。
- P1：项目模板、环境差异对比、项目复制。
- P2：团队共享、签名模板分发。

### 3.2 设备与资产
- P0：手动添加资产；IP/域名、端口、类型、厂商、标签、备注。
- P0：CSV 导入/导出；资产搜索、筛选、分组。
- P1：ONVIF 发现、授权网段扫描、设备信息探测。
- P1：资产状态历史、批量任务、重复资产合并。
- P2：更多厂商发现协议与 CMDB 集成。

### 3.3 网络诊断
- P0：Ping/ICMP（注明 ICMP 可能被策略阻断）、TCP 连接测试、DNS 查询。
- P0：本机网卡/IP/路由/DNS 信息查看。
- P0：Traceroute/Tracert 包装与结果结构化。
- P0：诊断超时、取消、结果导出。
- P1：端口范围检查、TLS 证书检查、HTTP 代理检查。
- P1：Pktmon/PCAPNG 集成、抓包过滤与导出。
- P2：流重组、深度协议解码、复杂网络拓扑。

### 3.4 HTTP/API 调试
- P0：GET/POST/PUT/PATCH/DELETE；URL、Query、Headers、JSON/文本/表单请求体。
- P0：响应状态、响应头、响应体、耗时、错误详情。
- P0：环境变量、变量遮蔽、请求历史。
- P1：OpenAPI 导入、集合、断言、请求串联、Webhook 接收。
- P1：OAuth 2.0、HMAC、自定义签名脚本（沙箱限制）。
- P2：定时回归、团队共享集合。

### 3.5 MQTT 调试
- P0：连接配置、MQTT 3.1.1；连接/断开、发布、订阅、消息查看。
- P0：TLS 基础选项、超时、Keep Alive、Client ID。
- P0：消息按 Topic/时间/关键字筛选，导出 JSON/CSV。
- P1：MQTT 5.0 属性、遗嘱、Retain、QoS 细节与连接指标。
- P1：Payload JSON/Hex/Base64 视图、消息模板、设备模拟。
- P2：协议扩展、批量模拟和性能压测（需明确安全边界）。

### 3.6 视频与流媒体
- P0：RTSP URL 配置、TCP/UDP 模式、连接与鉴权诊断；错误信息脱敏。
- P0：流信息与阶段结果；播放能力需明确依赖的媒体组件。
- P1：ONVIF 发现、能力查询、媒体 Profile 获取。
- P1：海康/大华 SDK 插件验证与设备信息/预览能力。
- P1：首帧耗时、分辨率、编码、帧率、断流事件等可观测指标。
- P2：GB/T 28181、HLS、RTMP、WebRTC、录像回放与多路墙。
- 备注：厂商 SDK 的许可、位数、运行库、版本与再分发条款须逐一确认。

### 3.7 日志与诊断任务
- P0：统一任务 ID、开始/结束时间、步骤、状态、耗时、错误和证据引用。
- P0：日志级别、关键字过滤、复制、导出。
- P0：任务取消、超时、异常隔离。
- P0：诊断结果状态：通过、失败、警告、跳过、未知。
- P1：规则引擎、故障模板、前后复测比较。
- P2：证据关联图、AI 解释（必须基于已采集证据并标注不确定性）。

### 3.8 通用开发者工具
- P0：JSON 格式化/校验、URL 编码/解码、Base64、时间戳转换、UUID。
- P1：JWT 解码（明确不代表签名验证）、文本差异、文件哈希、Hex 视图、正则测试。
- P2：XML/YAML/Protobuf、证书链工具、日志解析器插件。

### 3.9 报告中心
- P0：HTML 报告；包含产品版本、项目、目标、任务时间、结果、步骤、证据和建议。
- P0：报告敏感字段脱敏；报告可离线查看。
- P1：PDF/Markdown/CSV 导出、企业模板、签名与校验和。
- P2：项目级对比、自动巡检报告。

## 4. 关键用户流程

### 4.1 视频黑屏诊断
1. 选择项目 → 添加摄像机目标。
2. 输入 RTSP URL 或从项目凭据中引用认证信息。
3. 选择传输方式、超时和允许的诊断步骤。
4. 运行：DNS（如适用）→ TCP → RTSP 握手/鉴权 → SDP → 媒体接收 → 解码/首帧（可用时）。
5. 查看每一步状态、耗时、原始证据（脱敏）和下一步建议。
6. 导出报告；修复后运行复测并比较结果。

### 4.2 MQTT 联调
1. 新建连接配置并选择 MQTT 版本。
2. 配置 Broker、端口、TLS、认证和 Client ID。
3. 连接 → 订阅 Topic → 查看消息 → 发布测试消息。
4. 解析 Payload、检查 Topic/QoS/时间戳。
5. 保存为项目模板，导出脱敏诊断记录。

### 4.3 API 联调
1. 选择环境 → 新建请求。
2. 配置 URL、Headers、参数、请求体和认证。
3. 执行请求并查看状态、响应、耗时与异常。
4. 将请求保存到集合；设置断言并与其他请求串联（P1）。
5. 导出请求集合或诊断报告，敏感值默认不导出。

## 5. 信息架构与页面需求

### 5.1 主导航
- 工作台
- 设备与资产
- 接入调试
  - 视频/RTSP/ONVIF
  - MQTT
  - HTTP/API
  - 原始 TCP/UDP（P1）
- 网络诊断
- 诊断中心
- 开发者工具
- 项目与报告
- 设置/插件管理

### 5.2 核心页面
1. 工作台：项目切换、最近任务、常用工具、健康概览、快捷操作。
2. 项目页：资产、环境、连接配置、任务历史、项目模板。
3. 资产列表：表格、过滤、标签、导入导出、批量诊断。
4. 视频诊断页：左侧连接配置、中间预览/流信息、右侧阶段诊断、底部日志。
5. MQTT 工作台：连接面板、Topic 树、消息流、发布编辑器、连接日志。
6. API 工作台：集合/历史侧栏、请求编辑区、响应区、环境变量管理。
7. 网络工具页：目标输入、参数、运行状态、结果表格、路由可视化。
8. 诊断详情页：时间线、状态、证据、可能原因、复测对比。
9. 报告预览页：目录、摘要、步骤明细、证据、导出选项。
10. 设置页：外观、网络代理、存储、日志、隐私、插件和版本。

### 5.3 交互与视觉原则
- 以任务为中心，避免单纯的卡片墙；常用操作 1–2 次点击可达。
- 采用左侧主导航 + 顶部项目/环境切换 + 中央工作区 + 可折叠日志面板。
- 状态色统一：成功、失败、警告、运行中、未知；颜色之外必须有文字标签。
- 表格支持搜索、筛选、列宽调整、复制和导出。
- 长任务可取消，页面切换不应意外丢失任务。
- 错误消息要给出下一步可执行建议，不只显示异常堆栈。
- 支持浅色/深色主题、键盘快捷键和高 DPI。

## 6. 非功能需求

### 6.1 性能
- 冷启动目标：普通开发机上 5 秒内可进入工作台（基准机待定义）。
- UI 线程不得执行阻塞网络/文件/解码操作。
- 支持并发诊断任务上限配置；默认保守，避免影响现场网络。
- 大日志采用分页/虚拟化显示；抓包和视频数据不得全部载入内存。
- 任务取消后应在合理时间内释放连接与资源。

### 6.2 稳定性
- 单个插件异常不得导致主进程崩溃。
- 外部进程退出码、超时、标准输出和标准错误统一捕获。
- 项目文件采用版本号和迁移机制；写入使用原子保存策略。
- 未完成的任务需记录中断状态，不得误报成功。

### 6.3 安全与隐私
- 凭据与普通配置分离；Windows DPAPI 或 Windows Credential Manager 存储秘密。
- 日志、截图、抓包和报告默认脱敏密码、Token、Cookie、Authorization、URL 中凭据。
- 连接证书校验默认开启；不允许静默忽略 TLS 错误。
- 主动扫描需要明确目标范围和用户确认，提供速率限制与取消。
- 对外部命令使用参数化进程调用，禁止把用户输入直接拼接到 shell 命令。
- 插件需有来源、版本、签名/哈希和权限声明；不可信插件需显式确认。
- 本地数据清理、导出和保留策略可配置。

### 6.4 可维护性
- 核心业务与 UI 分离；协议模块有统一接口和契约测试。
- 结构化日志、可复现测试样例、故障码目录。
- 依赖锁定、SBOM、许可证清单和发布构建记录。
- CI 运行格式检查、静态分析、单元测试和打包验证。

## 7. 数据模型（概念级）

- Project：Id、Name、Description、CreatedAt、SchemaVersion、ActiveEnvironmentId。
- Environment：Id、ProjectId、Name、BaseUrl、ProxyProfileId、Variables（非秘密）。
- Asset：Id、ProjectId、Name、Type、Host、Port、Vendor、Model、Tags、Notes。
- ConnectionProfile：Id、ProjectId、Protocol、Endpoint、Options、SecretReference。
- DiagnosticRun：Id、ProjectId、TargetId、Kind、Status、StartedAt、EndedAt、AppVersion。
- DiagnosticStep：Id、RunId、Sequence、Name、Status、DurationMs、Summary、EvidenceRefs。
- LogEntry：Timestamp、Level、RunId、Module、Message、RedactedProperties。
- Report：Id、RunId、Format、CreatedAt、Path、Checksum。
- PluginManifest：Id、Version、ApiVersion、Capabilities、Publisher、Hash、SignatureStatus。

## 8. 验收标准（MVP）
- 安装/启动/卸载流程通过测试；首次启动可创建项目。
- 项目与资产增删改查、导入导出和重启持久化正常。
- Ping/TCP/DNS/路由工具可展示明确结果，支持超时和取消。
- HTTP 工具支持常见方法、Headers、JSON 请求体和响应查看。
- MQTT 可连接测试 Broker、订阅和发布消息，断线后状态准确。
- RTSP 模块至少能执行网络/协议阶段诊断，并对播放依赖和不支持情况做清晰说明。
- 日志可按 RunId 查询，敏感字段经过测试不会明文泄露。
- HTML 报告包含任务步骤、结果、时间、版本和脱敏证据。
- 核心模块具备单元测试与集成测试说明；构建流程可从干净环境重复执行。

## 9. 风险与待决事项
- 海康/大华 SDK 的版本、授权、设备型号覆盖与再分发许可。
- 媒体播放组件的许可证、硬件加速和编解码兼容性。
- Windows 版本最低支持范围及是否支持 ARM64。
- 是否集成 Npcap 等第三方抓包驱动，安装权限和许可证如何处理。
- 是否需要公司内部平台协议、GB/T 28181 私有扩展或项目特定认证。
- MVP 是否必须包含厂商 SDK 实际预览，还是先完成 RTSP/ONVIF 标准路径。
- 报告 PDF 生成、签名、项目加密与数据保留策略。

## 10. 版本路线
- V0.1：桌面骨架、项目、资产、日志、网络基础、HTTP。
- V0.2：MQTT、RTSP 诊断、HTML 报告、脱敏。
- V0.3：ONVIF、抓包适配、自动化测试、插件契约。
- V1.0：稳定性加固、安装包、升级/回滚、文档与验收。
- V1.2：补齐安装器失败升级恢复；真实文件占用下保留旧程序目录与卸载入口，
  成功升级后清理临时备份，不改变既有产品能力边界。
- V1.x：厂商 SDK、GB/T 28181、更多 IoT 协议、智能诊断。
