# LinkForge v1.2.0

正式发布页：
https://github.com/CiallorZ/ChinaTower-Tool/releases/tag/v1.2.0

标签 `v1.2.0` 指向提交 `5486fbee8c52205f0a004e8a872ae0e17a886704`；
历史标签 `v1.0.0` 与 `v1.1.0` 未移动。

LinkForge v1.2.0 是发布工程修复版本，重点是让失败的覆盖安装能够恢复旧程序，
而不是留下一个“应用文件缺失但仍显示已安装”的目录。

## 主要更新

- 升级前备份现有程序目录到
  `%LOCALAPPDATA%\LinkForge\upgrade-backup`。
- 覆盖安装失败时恢复旧 EXE、DLL、卸载器、快捷方式和程序目录内其他文件。
- 恢复不完整时保留备份并写入安装日志，不把失败报告成成功。
- 正常升级成功后删除临时备份；卸载仍保留用户项目和凭据数据。
- 验收新增真实文件占用失败注入，不再只验证“重复安装能成功”。

## 安全与范围边界

- 安装器和便携包**未签名**，Windows SmartScreen 可能提示未知发布者。
- 失败升级恢复不是系统级事务；磁盘损坏、权限撤销或长期文件占用仍可能导致
  恢复不完整，此时必须使用保留的备份和安装日志人工处理。
- 不支持自动更新、版本降级阻止或代码签名验证。
- 海康/大华厂商 SDK、GB/T 28181、RTP 接收、媒体解码与持续播放未交付。
- 抓包、端口/安全扫描与渗透攻防工具未交付，授权边界仍未确认。
- Windows 10 真机、32 位 Windows 安装流程、高 DPI 与完整辅助功能验收
  仍未完成。
