# 功能树（Feature Tree）

```text
LinkForge 视联网全链路调试工具箱
├─ 1. 工作台
│  ├─ 最近项目 / 最近任务
│  ├─ 常用工具 / 快捷命令
│  ├─ 诊断概览 / 任务运行状态
│  └─ 新建项目 / 导入项目
├─ 2. 项目与环境
│  ├─ 项目 CRUD / 项目模板
│  ├─ 环境管理（开发、测试、生产）
│  ├─ 配置导入导出 / Schema 迁移
│  └─ 项目级任务历史
├─ 3. 设备与资产
│  ├─ 手动添加 / CSV 导入导出
│  ├─ 资产搜索、筛选、分组、标签
│  ├─ 视频设备（摄像机、NVR、平台）
│  ├─ IoT 设备、网关、Broker
│  └─ ONVIF/授权网段发现（P1）
├─ 4. 视频接入
│  ├─ RTSP URL 构建器
│  ├─ 分阶段诊断：网络→握手→鉴权→SDP→RTP→解码
│  ├─ 播放与流信息（组件可用时）
│  ├─ ONVIF 发现与能力查询（P1）
│  ├─ 海康 SDK 适配器（P1）
│  ├─ 大华 SDK 适配器（P1）
│  └─ GB/T 28181、HLS、RTMP、WebRTC（P2）
├─ 5. IoT 与协议
│  ├─ MQTT 3.1.1 / 5.0（按阶段交付）
│  │  ├─ Broker 连接 / TLS / 认证
│  │  ├─ Topic 订阅 / 发布 / 消息流
│  │  ├─ Payload 文本/JSON/Hex/Base64
│  │  └─ 消息过滤、导出、模板、设备模拟
│  ├─ HTTP / HTTPS
│  ├─ WebSocket / SSE（P1）
│  ├─ TCP / UDP 原始报文（P1）
│  ├─ Modbus TCP/RTU（P1）
│  ├─ Zigbee 网关/协调器适配（P2）
│  ├─ CoAP / OPC UA（P2）
│  └─ 串口 / RS-485（P1）
├─ 6. 网络诊断
│  ├─ Ping / TCP 连接 / DNS
│  ├─ Traceroute / 本机网卡 / 路由表
│  ├─ TLS 证书 / 代理检查（P1）
│  ├─ 端口探测（授权范围、限速、取消）
│  ├─ Pktmon / PCAPNG（P1）
│  └─ 协议过滤、会话查看（P2）
├─ 7. API 工作台
│  ├─ 请求方法、URL、Query、Headers、Body
│  ├─ 认证：Basic/Bearer/API Key（P0）
│  ├─ 环境变量、历史、集合
│  ├─ 响应状态、Headers、Body、耗时
│  ├─ OpenAPI 导入 / JSON Schema（P1）
│  ├─ 断言、请求串联、Webhook（P1）
│  └─ OAuth2/HMAC/自动回归（P1/P2）
├─ 8. 全链路诊断中心
│  ├─ 任务编排与取消
│  ├─ 诊断步骤与统一状态模型
│  ├─ 结构化日志与证据关联
│  ├─ 故障规则库 / 复测比较（P1）
│  └─ AI 证据摘要（P2）
├─ 9. 安全中心
│  ├─ 授权资产范围
│  ├─ 开放端口与暴露面检查
│  ├─ TLS/证书/HTTP 基线
│  ├─ 凭据与敏感信息脱敏
│  ├─ 任务审计 / 扫描限速
│  └─ 整改与复测报告
├─ 10. 开发者工具
│  ├─ JSON / XML / YAML
│  ├─ URL / Base64 / Hex / 时间戳 / UUID
│  ├─ JWT 解码（非签名验证）
│  ├─ 正则 / 文本差异 / 文件哈希
│  └─ 日志解析 / Protobuf / 证书查看（P1/P2）
├─ 11. 报告中心
│  ├─ HTML 报告（P0）
│  ├─ PDF / Markdown / CSV（P1）
│  ├─ 模板、脱敏、校验和
│  └─ 历史报告、复测对比
└─ 12. 设置与扩展
   ├─ 外观 / 快捷键 / 代理 / 存储
   ├─ 插件清单、版本、能力、签名/哈希
   ├─ 日志等级与保留策略
   └─ 关于、诊断包、更新与回滚
```

## MVP 边界
P0 只承诺：项目与资产、网络基础诊断、HTTP/API、MQTT 基础、RTSP 阶段诊断、统一日志、HTML 报告、凭据保护与脱敏。ONVIF、厂商 SDK、抓包驱动、GB/T 28181、Zigbee 原生协调器适配按独立里程碑交付。
