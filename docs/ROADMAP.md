## 2. 版本路线（对齐 PRD §10）

| 版本 | 内容 | 关键门槛 |
| --- | --- | --- |
| V0.1 | 设计系统 + 壳层 + 项目/资产 + 日志 + 网络基础 + HTTP | 设计令牌 100% 覆盖；无硬编码视觉值；真实状态可用 |
| V0.2 | MQTT + RTSP 诊断 + HTML 报告 + 脱敏 | 脱敏在 UI/日志/报告三路径通过测试 |
| V0.3 | ONVIF + 抓包适配 + 自动化测试 + 插件契约 | 插件崩溃不影响主进程 |
| V1.0 | 稳定性加固 + 双架构安装包 + 文档验收 | 已发布未签名 Inno Setup 用户级安装器与 x64/x86 便携包；自动更新、自动回滚与代码签名不在本版范围 |
| V1.1 | 项目包、DPAPI 凭据库、CI 与发布可追溯性 | 已实现非秘密项目包与 CurrentUser DPAPI；正式发布仍为未签名双架构产物 |
| V1.x | 厂商 SDK + GB/T 28181 + 更多 IoT 协议 + 智能诊断 | 厂商许可与再分发条款已书面确认 |
